## Projects

| Folder | Description | Practices |
| --- | --- | --- |
| [Lab01](Lab01/) | Home page for Green Leaf Tea House: hero, tea list and visit information | Semantic HTML, CSS |

## Getting started

The projects are static pages, so there is nothing to install or build.

1. Clone the repository:

   ```bash
   git clone https://github.com/diutnh26/Front-End-Programming.git
   cd Front-End-Programming
   ```

2. Open the `index.html` file of any project folder in your browser.

If you use VS Code, the Live Server extension reloads the page automatically as you edit.
